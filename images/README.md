| Fayl nomi        | Xona turi         |
|-------------------|-------------------|
| `standard.jpg`     | Standard          |
| `twin.jpg`         | Twin              |
| `superior.jpg`      | Superior          |
| `suite.jpg`         | Suite (Люкс)      |

## 🛎 Xizmatlar rasmlari (SPA / basseyn / hammom / sauna / fitness)

| Fayl nomi              | Xizmat turi        |
|--------------------------|---------------------|
| `spa_zone.jpg`            | СПА зона            |
| `pool_1.jpg`, `pool_2.jpg` | Ёпиқ бассейн        |
| `hammam_1.jpg`, `hammam_2.jpg` | Турк ҳаммоми   |
| `sauna.jpg`                | Фин саунаси         |
| `gym_1.jpg`, `gym_2.jpg`   | Фитнес зал          |

Bir nechta rasm bo'lgan xizmatlar (basseyn, hammom, fitness) bot tomonidan avtomatik
ravishda **albom** (bir nechta rasm birgalikda) tarzida yuboriladi.

Agar biror rasm bu yerda bo'lmasa, bot avtomatik ravishda faqat matn (nom + tavsif) yuboradi
va xatolik bermaydi.

Rasm qo'shgandan/o'zgartirgandan keyin GitHub'ga push qiling (yoki "Upload files" orqali
yuklang) — Render avtomatik qayta deploy qiladi va rasmlar botda yangilanadi.
